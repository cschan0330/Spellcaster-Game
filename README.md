# My Summer Car fan wiki

Run `npm run dev` and open the Local URL printed by Vite (usually http://localhost:5173).

Build with `npm run build`, then inspect the production build with `npm run preview`.

Content lives in `src/content.js`, page markup in `src/template.js`, styles in `src/style.css`, and browser interactions in `src/main.js`. The dev and build scripts regenerate `index.html` with `render.mjs`, so the guides and FAQ remain readable without JavaScript.

Screenshots and web fonts require internet access. Checklist progress stays in this browser; the reset control clears it. See ASSET-CREDITS.md for sources and image notes.
